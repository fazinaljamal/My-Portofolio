About the Tahajji Project

Tahajji Project is a project aimed at learning and teaching how to read the Quran correctly and properly according to the rules of tajwid. This project is part of the learning program at SMA IT HSI Boarding School.

Through this project, I had the opportunity to learn more deeply about the science of tajwid of the Quran, starting from makhrajul huruf (articulation points), sifat-sifat huruf (characteristics of letters), to recitation rules such as mad, idgham, ikhfa, and others.

By understanding tajwid, we can recite the Quran more beautifully and in accordance with the guidance taught by the Prophet Muhammad SAW.
