About the Project

This is a Django-based website that uses raw SQL to manage a library database. The database is designed with several main tables such as books, members, borrowing, and returns, all interconnected through relationships. With CRUD (Create, Read, Update, Delete) features, users can manage library data efficiently. The website is designed with a focus on optimal user experience, intuitive navigation, and an attractive, responsive display across various devices.

I implemented modern design principles and web development best practices to create a professional and efficient solution. This website is fully responsive and optimized for fast performance.
